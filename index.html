    Upload monthly files

    Choose where the files belong — GitHub opens its upload page in that folder:

    1. Drag your Excel files onto the GitHub page — monthly files, or one file with many months. Any file name is fine.
    2. Click the green Commit changes button.
    3. That’s it. In about 2–3 minutes each file is saved as <year>/<Month>.xlsx (the month is read from its ReportDate), an existing month is replaced, and this dashboard refreshes by itself.

    You need to be signed in to GitHub with access to the private repository (the account that owns it).
